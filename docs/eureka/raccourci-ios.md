# Raccourci iPhone « Envoyer à Eurêka »

1. Dans **Raccourcis**, créer un raccourci nommé **Envoyer à Eurêka**. Dans ses détails, activer **Afficher dans la feuille de partage**. Accepter **Texte**, **URL** et **Images**.
2. Ajouter une condition sur le type de l’entrée. Pour une **image**, ajouter **Copier dans le presse-papiers**, puis **Ouvrir les URL** avec `https://vinicellar.ch/eureka/ajouter.html`.
3. Pour du **texte ou une URL**, ajouter **Encoder l’URL** sur l’entrée partagée. Construire un texte en concaténant `https://vinicellar.ch/eureka/ajouter.html#text=` et le résultat encodé. Ouvrir ce texte avec **Ouvrir les URL**.

Depuis Safari, Instagram, Notes ou Photos, choisir **Partager → Envoyer à Eurêka**. Le texte ou le lien est prérempli. Pour une photo, toucher **Coller une photo** et autoriser l’accès au presse-papiers si iOS le demande. Toucher **Ajouter** pour créer la fiche dans l’espace actif.

Si Safari demande une connexion, utiliser le compte Vinicellar, puis rouvrir Eurêka dans le même onglet pour retrouver le brouillon texte. Une photo peut aussi être choisie depuis la photothèque en cas de blocage du collage. Pour un texte trop long pour être ouvert comme adresse, le copier et le coller dans le formulaire.
